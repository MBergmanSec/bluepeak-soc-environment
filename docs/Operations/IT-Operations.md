# IT Operations

## Purpose

This document provides a high-level overview of the responsibilities and routine activities of the BluePeak Logistics IT team.

It also establishes the operational relationship between IT and Security during security investigations.

---

## IT Responsibilities

The IT team is responsible for maintaining the technology services used across BluePeak.

Core responsibilities include:

- User and identity administration
- Endpoint management and support
- Server administration
- Network administration
- Software deployment
- System patching and maintenance
- Backup operations
- Microsoft 365 administration
- Technical support for business systems

---

## Administrative Activity

Authorised IT personnel may perform administrative activity across BluePeak systems as part of their normal duties.

This may include:

- Remote administration
- PowerShell execution
- Software installation
- Service creation or modification
- Account and group changes
- System restarts
- Configuration changes
- Troubleshooting activity

Administrative activity should not automatically be considered malicious simply because privileged tools or accounts are involved.

Unexpected activity must still be investigated in context.

---

## IT and Security

IT and Security have separate but closely related responsibilities.

**IT** operates and maintains BluePeak's technology environment.

**Security Operations** monitors the environment, investigates suspicious activity and coordinates security response.

During an incident, Security may work with IT to:

- Confirm whether activity was authorised
- Obtain additional technical information
- Disable accounts
- Isolate systems
- Apply configuration changes
- Restore affected services

This separation provides clear ownership while supporting effective incident response.

---

## Operational Principle

BluePeak aims to maintain reliable technology services while making administrative activity visible enough to support security monitoring and investigation.
